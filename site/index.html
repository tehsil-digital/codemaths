About CodeMaths

CodeMaths is a free catalog of Lean 4 lessons built for undergraduate students learning formal theorem proving. Each lesson links to a short video and, where one exists, a companion code repo you can clone and run alongside it.

New lessons are added over time — head back to the catalog to search, sort, and page through what's available.
